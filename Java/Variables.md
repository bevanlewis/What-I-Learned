# Variables

In Java, variables are containers that hold data values. Each variable must be declared with a specific data type, which determines the kind of values it can store. There are several types of variables in Java:

## Example

```java
//type int
int localInt = 30;

//type double - store decimals
double localDouble = 3.14;

//type boolean
boolean localBoolean = true;

//type char - store single character
char localChar = 'A';

//type String
String localString = "Hello, World!";
```
