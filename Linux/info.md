What is an Operating System?

- Software that manages the hardware and resources.
- Allows interaction with hardware

What is Unix?

- Family of operating systems
  Eg: Linux, Solaris, BSD, MacOS

What is Linux?

- Linux is a Unix-like operating system.
- Free and open source versions of Unix.

What is the Linux kernel?

- The kernel is the core of the operating system.
- It is the part of the operating system that manages the hardware.

What is a Linuux distribution?

- A Linux distribution is a collection of software that includes the Linux kernel and other software.

  Each distribution has a unique set of software.

  - System utilities
  - Graphical user interface

Linux Shell vs Linus terminal

- Shell is a command line interface.
- Terminal is a graphical user interface to interact with the shell.
