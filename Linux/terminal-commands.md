# Common Linux Terminal Commands

| Command   | Description                                                         | Example                                    |
| --------- | ------------------------------------------------------------------- | ------------------------------------------ |
| `ls`      | Lists directory contents.                                           | `ls`                                       |
| `cd`      | Changes the current directory.                                      | `cd /path/to/directory`                    |
| `pwd`     | Prints the current working directory.                               | `pwd`                                      |
| `cp`      | Copies files or directories.                                        | `cp source_file destination_file`          |
| `mv`      | Moves or renames files or directories.                              | `mv old_name new_name`                     |
| `rm`      | Removes files or directories.                                       | `rm file_name`                             |
| `mkdir`   | Creates a new directory.                                            | `mkdir directory_name`                     |
| `rmdir`   | Removes an empty directory.                                         | `rmdir directory_name`                     |
| `touch`   | Creates an empty file or updates the timestamp of an existing file. | `touch file_name`                          |
| `chmod`   | Changes file permissions.                                           | `chmod 755 file_name`                      |
| `chown`   | Changes file owner and group.                                       | `chown owner:group file_name`              |
| `cat`     | Concatenates and displays file content.                             | `cat file_name`                            |
| `grep`    | Searches for patterns in files.                                     | `grep 'pattern' file_name`                 |
| `find`    | Searches for files in a directory hierarchy.                        | `find /path -name file_name`               |
| `ps`      | Displays information about active processes.                        | `ps aux`                                   |
| `kill`    | Terminates processes.                                               | `kill process_id`                          |
| `man`     | Displays the manual for a command.                                  | `man command_name`                         |
| `echo`    | Displays a line of text.                                            | `echo "Hello, World!"`                     |
| `df`      | Displays disk space usage.                                          | `df -h`                                    |
| `du`      | Displays directory space usage.                                     | `du -sh directory_name`                    |
| `tar`     | Archives files.                                                     | `tar -cvf archive_name.tar directory_name` |
| `wget`    | Downloads files from the internet.                                  | `wget http://example.com/file`             |
| `curl`    | Transfers data from or to a server.                                 | `curl http://example.com`                  |
| `ssh`     | Connects to a remote machine via SSH.                               | `ssh user@hostname`                        |
| `top`     | Displays real-time system information.                              | `top`                                      |
| `nano`    | Opens the nano text editor.                                         | `nano file_name`                           |
| `vim`     | Opens the vim text editor.                                          | `vim file_name`                            |
| `apt-get` | Package handling utility for Debian-based distributions.            | `sudo apt-get install package_name`        |
| `yum`     | Package manager for RPM-based distributions.                        | `sudo yum install package_name`            |
