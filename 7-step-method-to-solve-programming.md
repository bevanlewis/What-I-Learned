# 7 Step Method to Solve Programming Problems

1. Work Example by hand

- Solve small instance by hand
- Clarify the problem
- You might lack some domain knowledge

2. Write down what you did

- Write down exact steps for the instance that you solved

3. Find patterns

- Create an algorithm for any instance
- Repetition, conditions and values are the key
- Maybe repeat steps 1,2 and 3

4. Check by hand

- Check if your algorithm works with other different inputs

5. Translate to code

- Translate your algorithm to code

6. Run test cases

- Run your code with test cases

7. Debug failed test cases

- Algorithmic problem? go back to step 3
- Implementation problem? go back to step 5
